# PairProgram

## Описание
Приложение для работы с CSV данными и с авторизацией и регистрацией.

## Установка
Инструкции по установке
```bash
git clone https://github.com/faybit/LabWork3.git
```

## Системные требования
1. .NET 10.0 SDK или выше
2. Операционная система Windows 10 / 11

## Котрибьютинг

1. **Обсуждение:** Перед тем как писать код, создайте тему в Issues, чтобы обсудить баг или новую фичу с мейнтейнерами.
2. **Ветка:** Сделайте форк репозитория и создайте новую ветку для работы: `git checkout -b feature/ваша-фича` (или `fix/описание-бага`).
3. **Код и стиль:** Пишите чистый код, проверяйте его линтером перед отправкой и убедитесь, что проект запускается. Коммиты называйте кратко и по делу (например, `feat: add search block` или `fix: user profile memory leak`).
4. **Pull Request:** Отправьте ветку в свой форк и откройте PR в основную ветку проекта. В описании обязательно укажите, какую задачу решает ваш код.
